# Security Policy

## Supported Versions

Since this repository contains personal dotfiles and custom scripts, only the latest commit on the `main` branch is actively supported and maintained.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

Security is a priority, especially when handling system configurations, environment variables, and automated shell scripts.

If you discover a potential security vulnerability (such as exposed hardcoded secrets, dangerous script permissions, or command injection risks in custom scripts):

1. **Do NOT open a public issue or pull request.**
2. Report the vulnerability privately by sending an email to **[laksana.kresna.dev@gmail.com]** (or via GitHub Private Vulnerability Reporting if enabled on this repository).
3. Include detailed steps to reproduce the issue, along with any relevant proof-of-concept scripts or logs.

### Response Timeline
- **Acknowledgement:** Within 48 hours of receiving the report.
- **Assessment & Fix:** Aimed to be patched within 7–14 days depending on the severity.

Thank you for helping keep these dotfiles safe and secure!
